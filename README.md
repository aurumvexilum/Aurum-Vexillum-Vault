# WAX Vault

This repository contains a web wallet foundation and a Capacitor path for Android/iOS packaging.

## Run the web app

```bash
npm install
npm run dev
npm run build
```

## Android/iOS wrapper

After installing the Android Studio and Xcode prerequisites:

```bash
npx cap init "WAX Vault" "com.aurumvexilum.waxvault" --web-dir dist
npm run build
npx cap add android
npx cap add ios
npm run mobile:sync
npx cap open android
npx cap open ios
```

The native projects are intentionally generated by Capacitor rather than committed here. Use OS secure storage plugins for native production builds; do not rely on IndexedDB alone on mobile.

## Production architecture

- `src/lib/wax.ts`: WAX RPC adapter, endpoint health/failover, token metadata, AtomicAssets, signing and validation.
- `src/lib/secure-storage.ts`: encrypted web vault adapter. Native builds should provide a Keychain/Keystore adapter behind the same interface.
- UI layer: presentation only; move transaction workflows into a service/store before production.
- Recommended production modules: `domain` (accounts, assets, transactions), `application` (use cases), `infrastructure` (RPC/indexers/storage), and `presentation` (web/native screens).
- Add CSP, HTTPS, dependency pinning, reproducible builds, SAST/dependency scanning, audit logging without secrets, rate limits, endpoint health monitoring, and independent security review.

## Security and recovery warnings

This is not an audited wallet. The mnemonic-to-key conversion is a starter implementation and must be replaced with a documented, audited WAX/EOS derivation implementation before real funds are supported. Account names and public keys are not created by a mnemonic alone; WAX accounts require on-chain account creation and permissions. Message signatures are local K1 signatures over SHA-256 and are not a universal wallet-connect signature standard.

Never upload recovery phrases or private keys. Verify token contracts and precision from authoritative sources. Token list data is untrusted display metadata and must not automatically authorize transfers.
