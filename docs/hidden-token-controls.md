# Hidden token controls

Token hiding is a local display preference. It does not burn, transfer, freeze, or otherwise change tokens on-chain.

- Hide or show individual tokens from the Dashboard or Assets screen.
- Hidden tokens remain available to trading and transaction services.
- Hidden-token preferences are persisted locally with the active dashboard account.
- “Show all tokens” clears the local hidden-token list.
- The contract and symbol are used together as the token identity to avoid collisions.

Hidden balances must never be described as zero, sold, or unavailable; the UI labels them as hidden when managed from the Assets screen.
